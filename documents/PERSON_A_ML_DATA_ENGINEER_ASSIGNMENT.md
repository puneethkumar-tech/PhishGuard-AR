## Important dataset rules

- Inspect actual columns and label values first; the README schema map is only a starting hypothesis.
- Do not assume all eight files are compatible.
- Treat malware metadata separately if it does not contain raw message text.
- Normalize labels explicitly and save the mapping.
- Deduplicate before splitting.
- Use fixed seeds.
- Keep source names in the processed data.
- Report class balance and sample counts for every source.

## Baseline requirements

Start with:

- Text normalization
- Word TF-IDF n-grams
- Character TF-IDF n-grams if time permits
- Logistic Regression or LinearSVC
- Accuracy, precision, recall, F1
- Confusion matrix
- Per-source results
- Clean test set saved for Person B

Do not promise F1 > 0.95 before measuring it. Report the real result.

## Explainability requirements

Provide one of:

- TF-IDF coefficient-based feature evidence for linear models, or
- SHAP if it can be implemented and validated within the time limit.

Use wording such as:

> These terms contributed to the model decision; they are not proof that the message is malicious.
